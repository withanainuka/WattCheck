# Home Energy Usage & Cost Analyzer
This is a simple Python project I made to look at the electricity usage in my home throughout the year.
The project uses estimated monthly energy data based on my house size, number of people living there, appliances, and normal energy use.

## Features
- Calculates total yearly electricity usage
- Finds the average monthly electricity use
- Shows the highest and lowest usage months
- Estimates monthly electricity costs using Ontario Time-of-Use rates
- Finds the most and least expensive months
- Creates graphs for electricity usage and cost

## Tools Used
- Python
- Matplotlib

## What I Learned
This project helped me get more comfortable with Python and working with basic energy data.
I also learned how electricity use can change during different times of the year and how Time-of-Use pricing can affect electricity costs.
